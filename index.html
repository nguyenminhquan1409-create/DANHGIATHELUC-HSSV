Cấu Hình Liên Kết Firebase Để Đưa Lên GitHub Pages

Dán cấu hình firebaseConfig từ Firebase Console của bạn vào ô dưới đây để đồng bộ tài khoản, kiểm soát IP và lưu file đối chiếu khi chạy trên GitHub.

Đang kiểm tra kết nối Firebase...
Hướng dẫn 4 bước đưa lên GitHub hoạt động 100%:
  1. Vào Firebase Console → Tạo Project mới → Thêm ứng dụng Web (</>) và copy đoạn firebaseConfig.
  2. Trong Firebase Console, vào mục Authentication → Sign-in method → Bật Anonymous (Ẩn danh).
  3. Vào mục Firestore Database → Bấm Create database → Mở tab Rules và đặt quyền cho phép đọc/ghi: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  4. Dán firebaseConfig vào ô bên trái → Bấm "Tải File index.html (Đã gắn Firebase)" rồi upload file index.html đó lên kho lưu trữ GitHub Pages của bạn.
